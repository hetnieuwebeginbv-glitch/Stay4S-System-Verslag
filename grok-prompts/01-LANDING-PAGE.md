# PROMPT 1: Stay4S Landing Page

Plak dit in Grok:

---

Je bent een senior web designer die werkt voor Stay4S B.V. — een Europees, privacy-first, AI-native technologie ecosysteem. Bouw een spectaculaire landing page in één HTML bestand (inline CSS + JS, geen externe dependencies).

DESIGN SYSTEM:
- Achtergrond: puur zwart (#000000)
- Tekst: wit (#FFFFFF)
- Accent: teal/mint groen (#00FF9D)
- Secundair: donkergrijs (#666666)
- Font: system sans-serif voor body, monospace voor labels/badges
- Stijl: minimalistisch, tech, dark, premium — zoals Apple meets cybersecurity

STRUCTUUR (scroll down, full-page sections):

1. HERO — Volledig scherm, gecentreerd
   - Badge bovenaan: "● STAY4S · SOVEREIGNTY STACK · 2026" (mono, teal punt)
   - Titel: "Stay4S" (groot, gradient wit→teal)
   - Subtitel: "Een compleet digitaal ecosysteem dat van jou is. Geen Big Tech. Geen meeluisterende cloud. Geen verborgen tracking. Jij bezit de infrastructuur."
   - Stats rij: 12 Eigen Diensten | 5/7 Kill Switches | 0 Big Tech Dep | ∞ Jouw Data

2. PHONE MOCKUPS — Twee telefoons naast elkaar
   - Links: GrokPhone lock screen (zwart bg, tijd 12:01, "Dinsdag 1 September", "● GROKPHONE · STAY4OS" in teal, kill-switch lijst met toggles: GPS off, Camera off, Mic off, Radio off, TPU on, "5/7 SEALED" badge, "↑ Ontgrendel" onderaan)
   - Rechts: Stay4S Command Center status scherm (lijst van diensten met status: Mail ● Online, Chat ● Online, AI Core ● Active, Mesh Net ● 4 nodes, VPN ● Protected, Identity ● Verified, App Store ● 12 apps, Threats: 0 active, "All systems sovereign" onderaan)
   - Telefoon frame: 280px breed, afgeronde hoeken, subtiele teal glow shadow

3. ARCHITECTUUR — Drie lagen, verticale kaarten
   - "📱 GrokPhone — Pixel 9 Pro" → EDGE tag → "Stay4OS ROM met AetherCore AI op Tensor TPU. LocationGuard GPS kill. GrokSecureMsg post-quantum mesh. 7 hardware kill-switches."
   - "🖥️ Hetzner AX102 — EU Sovereign Cloud" → CORE tag → "12 zelfgehoste diensten: Mail, Chat, Identity, AI, App Store, Search, Maps, Cloud, Wallet, VPN. Docker, open-source."
   - "📡 Raspberry Pi 5 — Edge Nodes" → MESH tag → "Meshmatic LoRa mesh netwerk. Pi-hole DNS + ad blocking. Off-grid communicatie."

4. SOVEREIGNTY STACK — Grid van 12 service kaarten (responsive grid, min 260px per kaart)
   Elke kaart: emoji icon, titel, 1 zin beschrijving, "Vervangt [Big Tech product]" in kleine tekst met teal highlight op de Big Tech naam.
   - 📧 Stay4S Mail — Eigen mailserver, Mailu, E2E encryptie — Vervangt Gmail
   - 💬 Stay4S Chat — Matrix/Synapse, federated, encrypted — Vervangt WhatsApp
   - 🤖 Stay4S AI — Ollama + StayLM, lokale AI, geen cloud API — Vervangt ChatGPT/Grok API
   - 🔐 Stay4S Identity — Keycloak SSO, één login alles — Vervangt Google Account
   - 📲 Stay4S App Store — F-Droid repository, open-source — Vervangt Google Play
   - 🔍 Stay4S Search — SearXNG meta-search, geen tracking — Vervangt Google Search
   - 🗺️ Stay4S Maps — OpenStreetMap tile server — Vervangt Google Maps
   - ☁️ Stay4S Cloud — MinIO + Nextcloud, S3 storage — Vervangt Google Drive
   - 💳 Stay4S Wallet — BTCPay Server, zelfgehost — Vervangt Google Pay
   - 🛡️ Stay4S VPN — WireGuard op eigen server — Vervangt NordVPN
   - 🌐 Stay4S DNS — Pi-hole + Unbound, ad blocking — Vervangt 8.8.8.8
   - 📡 Stay4S Mesh — Meshmatic LoRa + MQTT, off-grid — Vervangt Cellular backup
   Hover effect: border wordt teal, lichte teal glow

5. GROKPHONE FEATURES — Grid van 4 kaarten
   - 🧠 AetherCore — "Grok op de Tensor TPU. Geen cloud-profiel, geen meeluisterende API-laag."

   - "Ontgrendel het toestel. Flip de switches. Neem controle." (groot)

- Eén HTML bestand, alle CSS inline in <style>, alle JS inline in <script>
- Geen externe fonts, libraries of CDN dependencies
- Volledig responsive (mobile-first)
- Subtle animaties: fade-in op scroll, glow pulse op teal elementen
- Donkere, premium uitstraling — denk Linear.app meets cybersecurity
