# Stay4S x Grok — Super Prompt Collection

Deze prompts zijn copy-paste ready voor Grok. Plak ze één voor één in Grok en plak het resultaat terug naar Stay4Compa (je Superagent) voor review en opslag.

## Hoe dit werkt
1. Jij plakt een prompt in Grok
2. Grok genereert code/design/content
3. Jij plakt het resultaat terug naar mij (Stay4Compa)
4. Ik review, sla op in InfoVault, en geef feedback
5. We itereren
